# diffcp: Differentiating Through Cone Programs

R port of the Python `diffcp` package, mirroring Agrawal, Barratt, Boyd,
Busseti, and Moursi (2019). Computes the derivative of the optimal
solution map of a convex cone program with respect to its data, via the
implicit-function theorem on the homogeneous self-dual embedding.

## Details
